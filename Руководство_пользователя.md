# Rich Slicer 2.7.2 — руководство пользователя

**Rich Slicer** — скрипт для Adobe Photoshop с русским окном управления. Он нарезает одно открытое изображение для Wildberries и OZON, показывает области разреза, сохраняет JPEG и не изменяет оригинальный документ.

Проверен пользователем в Photoshop 2023 (24.7.1). Это скрипт **JSX / ScriptUI**, а не UXP-панель. Для запуска не требуются Adobe UXP Developer Tool и установочный файл CCX.

## 1. Как установить и запустить

### Способ А — без установки (самый простой)

1. Скачайте архив `Rich_Slicer_RU_v2_7_2_STABLE_ZOOM_PREVIEW.zip` и распакуйте его.
2. Откройте нужное изображение в Photoshop.
3. В Photoshop выберите **Файл → Сценарии → Обзор…**.
4. Укажите файл `Rich_Slicer_Easy.jsx` из распакованной папки.
5. Откроется окно **Rich Slicer 2.7.2 — Wildberries и OZON**.

### Способ Б — добавить в меню Photoshop (Windows)

1. Закройте Photoshop.
2. Распакуйте архив полностью — файлы `Install_Windows.bat`, `Install_Windows.ps1` и `Rich_Slicer_Easy.jsx` должны оставаться в одной папке.
3. Запустите `Install_Windows.bat` двойным щелчком. Если Windows запросит разрешение администратора для копирования в папку Photoshop, подтвердите его.
4. После завершения откройте Photoshop и выберите **Файл → Сценарии → Rich_Slicer_Easy**.

Установщик ищет папки `Presets\Scripts` установленных Photoshop в стандартных каталогах Adobe в Windows и копирует туда JSX. Если папка не найдена или установка не завершена, воспользуйтесь способом А. При обновлении можно ещё раз запустить установщик, заменив старый JSX, либо запустить новый через «Обзор…».

## 2. Перед началом работы

Откройте длинное исходное изображение (например, PSD или JPEG). Для автоматического сохранения рядом с ним предварительно сохраните документ на диск. Если документ ещё не сохранён, выберите папку вручную в блоке «Сохранение».

В верхней строке программы указаны размеры исходника в пикселях и статус загрузки фото-превью.

## 3. Общие настройки

| Элемент | Что делает |
|---|---|
| **Качество JPEG (1–12)** | Задаёт качество всех экспортируемых JPEG. По умолчанию `12` — максимальное. |
| **Все файлы в одну папку (по умолчанию)** | Включено при открытии. Wildberries сохраняется в общую корневую папку, OZON — в её подпапки. |
| **Выбрать папку…** в блоке «Сохранение» | Выбирает общую корневую папку для результатов. По умолчанию это `SEGMENTS` рядом с сохранённым исходником. |
| **Перезаписывать существующие JPEG** | По умолчанию **выключено**. Если файл с таким именем уже есть, экспорт останавливается с сообщением. Если включить — совпадающие JPEG будут заменены **без подтверждения**. |

## 4. Вкладка Wildberries

| Элемент | Что делает |
|---|---|
| **Высота сегмента** | Высота одной части в пикселях; по умолчанию `900`. Последняя часть может быть короче. |
| **Привести ширину к 1440 px** | Включено по умолчанию: перед нарезкой копия изображения пропорционально масштабируется до ширины 1440 px. Если снять галочку, используется исходная ширина. |
| **Миниатюра и разрезы** | Показывает исходную картинку, разделённую на части. Нажмите на область, чтобы включить или исключить её из экспорта. |
| **10 возможных частей** | Галочки рядом с номерами сегментов; сохраняются только отмеченные. Недоступные части не выбираются. |
| **Строка «Сегментов: … / 10»** | Показывает расчётное количество частей. Если больше 10, скрипт не разрешит экспорт WB: увеличьте высоту сегмента. |

Для Wildberries в программе предусмотрены **не более 10 частей** и ограничение размера одной части **не более 1440 × 9000 px**. Файлы называются `Rich_01.jpg`, `Rich_02.jpg`, `Rich_03.jpg` и так далее. Номер относится к месту части в исходном изображении: если снять галочку со второй части, имя третьей не изменится.

## 5. Вкладка OZON

**Desktop и Mobile нарезаются независимо из оригинала**, а не друг из друга.

| Режим | Ширина | Максимальная высота каждого JPEG | Папка |
|---|---:|---:|---|
| **DESKTOP** | 1200 px | 3000 px | `OZON/1200` |
| **MOBILE** | 640 px | 1400 px | `OZON/640` |

В каждой колонке есть отдельные элементы:

| Элемент | Что делает |
|---|---|
| **Первая часть** | Поле точного ввода высоты первого сегмента в пикселях. Значение ограничивается максимумом Desktop или Mobile. |
| **Авто** | Сбрасывает ручную настройку и делит всю длину **на максимально равные части**, не превышающие установленную высоту. |
| **Ползунок** | Позволяет двигать первую границу вверх/вниз. Остальные сегменты автоматически перераспределяются. |
| **Увеличенное фото-превью** | Показывает крупный участок изображения **вокруг первой синей линии разреза**, а не всё длинное полотно. Линию можно двигать мышью. |
| **Высота … / файлов: …** | Показывает полную высоту после масштабирования и количество файлов для соответствующего режима. |
| **Авто, поровну / Ручная** | Показывает выбранный способ нарезки и лимит высоты. |

**Как работает ручная нарезка:** вы меняете только **первую** границу. Первая часть получает выбранную высоту, а **вся оставшаяся длина** автоматически делится на равные сегменты в пределах лимита. Программа не выбрасывает нижние части изображения. В Desktop и Mobile свои независимые границы, поэтому количество файлов может различаться.

**Как работает увеличение:** при перетаскивании границы синяя линия меняется сразу; фотография центрируется вокруг нового места разреза **после отпускания мыши или ползунка**. Это сделано, чтобы Photoshop не мигал из-за непрерывного создания миниатюр.

**Обновить фото-превью** — заново создаёт миниатюры из открытого документа (Wildberries и обе колонки OZON). Используйте, если фото не отображается или превью нужно перезагрузить.

**Выбрать папку…** в блоке «Папки OZON» — выбирает **корневую папку OZON**, внутри которой автоматически создаются `1200` и `640`. Кнопка доступна, когда снята общая галочка «Все файлы в одну папку».

## 6. Кнопки внизу программы

| Кнопка | Действие |
|---|---|
| **Сохранить WB** | Экспортирует только выбранные части Wildberries. |
| **Сохранить OZON** | Экспортирует все рассчитанные Desktop- и Mobile-фрагменты в две отдельные папки. |
| **Сохранить всё** | Выполняет экспорт и Wildberries, и OZON. |
| **Закрыть** | Закрывает окно Rich Slicer. |
| **Результат экспорта** | Не кнопка, а информационное поле: показывает статус, количество сохранённых JPEG, пути или текст ошибки. |

## 7. Куда сохраняются файлы

Если галочка **«Все файлы в одну папку» включена** и исходник расположен в папке `Товары`, программа по умолчанию создаёт такую структуру:

```text
Товары/
├── Исходник.psd
└── SEGMENTS/
    ├── Rich_01.jpg
    ├── Rich_02.jpg
    ├── ...
    └── OZON/
        ├── 1200/
        │   ├── OZON_01.jpg
        │   ├── OZON_02.jpg
        │   └── ...
        └── 640/
            ├── OZON_01.jpg
            ├── OZON_02.jpg
            └── ...
```

Если выбрать другую общую папку, эта же структура создаётся в ней. Если **снять галочку общей папки**, WB сохраняется в `SEGMENTS` рядом с исходником, а OZON — в отдельно выбранную корневую папку с подпапками `1200` и `640`.

## 8. Пример нарезки

Открыт исходник **1440 × 6300 px**.

- **Wildberries:** при высоте 900 px получается **7 частей** (1440 × 900 px каждая), если все галочки установлены.
- **OZON Desktop:** масштабирование до ширины 1200 px даёт высоту 5250 px. Авторазделение: **2 файла 1200 × 2625 px**.
- **OZON Mobile:** независимое масштабирование до 640 px даёт высоту 2800 px. Авторазделение: **2 файла 640 × 1400 px**.

Если в Desktop вручную установить первую часть **3000 px**, получится **3000 + 2250 px**. Если отдельно в Mobile установить **1000 px**, получится **1000 + 900 + 900 px**.

## 9. Важные замечания

- **Оригинальное изображение не изменяется.** Экспорт производится из временных копий документа.
- При выключенной перезаписи совпадающие имена блокируют запуск экспорта; при включённой — файлы заменяются без отдельного вопроса. **Лишние старые JPEG программа не удаляет**: если раньше было 5 частей, а теперь 3, оставшиеся старые файлы могут находиться в папке.
- Если WB показывает больше 10 сегментов, увеличьте высоту части или измените параметры. Слишком большие сегменты (выше 9000 px) также не будут экспортированы.
- При ошибке загляните в поле **«Результат экспорта»** внизу окна.
- Если пункт Rich Slicer в меню Photoshop остался старой версией, откройте **Файл → Сценарии → Обзор…** и укажите файл версии 2.7.2 напрямую либо повторите установку и перезапустите Photoshop.
- Программа предназначена для версий Photoshop с поддержкой JSX/ScriptUI. Работа подтверждена пользователем на Photoshop 2023 (24.7.1); другие версии желательно проверять отдельно.
