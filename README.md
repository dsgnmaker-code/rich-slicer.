# ✂️ Rich Slicer 2.7.2

### Бесплатный скрипт Photoshop для Wildberries и OZON

**Rich Slicer** — удобный инструмент для автоматической нарезки длинного Rich-контента под маркетплейсы Wildberries и OZON.

Больше не нужно вручную создавать отдельные изображения, рассчитывать размеры и сохранять каждый файл. Программа делает это автоматически!

## 🚀 Возможности

**🟣 Wildberries**
- Нарезка до 10 сегментов.
- Выбор нужных частей галочками.
- Настройка высоты и ширины.

**🔵 OZON**
- Desktop — 1200 × до 3000 px.
- Mobile — 640 × до 1400 px.
- Независимая нарезка Desktop и Mobile.
- Ручная и автоматическая настройка границ.

**⚙️ Дополнительно**
- Реальное увеличенное превью места разреза.
- Качество JPEG от 1 до 12.
- Автоматическое создание папок.
- Защита оригинального изображения.
- Полностью русский интерфейс.

## 🛠 Быстрый запуск

Откройте Photoshop → **Файл → Сценарии → Обзор** → выберите `Rich_Slicer_Easy.jsx`.

Никаких дополнительных плагинов Adobe устанавливать не нужно.

## ✅ Совместимость

Программа проверена на **Adobe Photoshop 2023 (24.7.1)**. Совместимость с другими версиями требует тестирования.
