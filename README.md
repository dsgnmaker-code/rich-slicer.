# Rich Slicer 2.7.2 — Photoshop-скрипт для Wildberries и OZON

**Rich Slicer** — бесплатный инструмент для автоматической нарезки длинного Rich-контента в Adobe Photoshop. Русский интерфейс, визуальное превью и экспорт JPEG. Не требует установки Adobe UXP Developer Tool.

> **Статус:** стабильная по пользовательскому отзыву версия **2.7.2** для Photoshop 2023 (24.7.1). Другие версии Photoshop необходимо проверять отдельно. Исходный файл не меняется — экспорт идёт из временных копий.

## Скачать и запустить

**Готовый архив:** [`downloads/Rich_Slicer_v2.7.2.zip`](downloads/Rich_Slicer_v2.7.2.zip)

**Самый простой способ** (без установки):
1. Скачайте и распакуйте ZIP.
2. Откройте нужное изображение в Photoshop.
3. Перейдите в **Файл → Сценарии → Обзор…**.
4. Выберите `Rich_Slicer_Easy.jsx`.

**Установка в меню на Windows** (необязательно): закройте Photoshop, распакуйте ZIP и запустите `Install_Windows.bat`. Установщик копирует JSX в найденные папки `Presets/Scripts` и может запросить права администратора. После перезапуска Photoshop скрипт будет в **Файл → Сценарии → Rich_Slicer_Easy**.

## Возможности

| Раздел | Что делает |
| --- | --- |
| **Wildberries** | Нарезка изображения на сегменты, выбор нужных частей галочками (до 10) |
| **OZON Desktop** | Независимое масштабирование исходника до **1200 px** по ширине; сегменты **не выше 3000 px** |
| **OZON Mobile** | Независимое масштабирование исходника до **640 px** по ширине; сегменты **не выше 1400 px** |
| **Автоматическая нарезка OZON** | Делит изображение на максимально равные части в рамках лимитов |
| **Ручная нарезка OZON** | Можно изменить **первую** границу мышью, ползунком или числом; остальные сегменты рассчитываются автоматически |
| **Предпросмотр** | Фото вокруг линии разреза увеличено; при движении обновляется линия, а фотография — после завершения действия |
| **JPEG** | Качество от 1 до 12, выбор папки и опция перезаписи |

## Куда сохраняются файлы

При включённой настройке **«Все файлы в одну папку»** (по умолчанию):

```text
Рядом с исходником/
├── Исходник.psd
└── SEGMENTS/
    ├── Rich_01.jpg
    ├── Rich_02.jpg
    └── OZON/
        ├── 1200/
        │   ├── OZON_01.jpg
        │   └── OZON_02.jpg
        └── 640/
            ├── OZON_01.jpg
            └── OZON_02.jpg
```

Количество Desktop- и Mobile-файлов **может отличаться**. Для OZON каждая серия создаётся независимо из исходника.
